PROJECT NAME

Project IronLog

Version 1.0

==========================================================
PROJECT GOAL
==========================================================

Create a beautiful, premium, mobile-first Progressive Web App (PWA) that serves as my personal gym companion.

The application will be:

• developed locally
• committed to GitHub
• hosted on GitHub Pages
• installed on my iPhone Home Screen
• work offline
• store everything locally
• never require a backend

The experience should feel closer to Apple's Fitness app than a typical HTML website.
